## Design Specificity Verdict

**Split verdict: the content is specific, the container is generic.**

The actual sentences are non-transferable: "an agent can draft anything and send nothing," the fee-weighting math, "32 H100s to 4," "the lower number wins." No other founder could paste this in unchanged. The side rail's live bidirectional scroll tracking is genuinely custom engineering, not a scrollspy library default.

But the page's shape is a template: H1 name -> tagline -> anchor row -> nine repeating blocks of "heading / small meta line / paragraph" (2 companies + 4 work samples + 3 articles), all at the same type scale, in the same 680px column. Strip the words out and this is indistinguishable from hundreds of other founder sites.

## Overall Impression

The site isn't cluttered, it's underloaded. The cognitive-load checklist passes 7/8 items. The fix isn't decluttering, it's spending the hierarchy budget currently unused. The biggest single opportunity: nine content blocks (2 companies, 4 work samples, 3 articles) that all look identical currently ask a skimming investor to read every word just to tell "flagship live company" from "unlaunched product" from "blog post."

## What's Working

1. The writing carries real signal: specific numbers, named tradeoffs, honest downsides.
2. `MethodLine`'s live bidirectional tracking is genuinely custom: recomputes from real scroll position every tick, un-lights on scroll-back, respects reduced-motion.
3. Disciplined token system: one column, one 8px scale, edge cases handled cleanly (no photo placeholder box when there's no photo, no invented dates).

## Priority Issues

**[P1] Nine near-identical blocks, one visual grammar**
Companies, work samples, and articles all render as heading -> small meta line -> paragraph, same size, same column. An investor can't tell "live venture" from "past employer credit" from "blog post" without reading every word.
Fix: give each block type its own visual identity within the palette; bigger/bolder brown deck treatment for companies, a tighter/denser rhythm for work samples so they read as supporting evidence not peers, a different baseline grid for articles.
Command: /impeccable layout

**[P1] Flat type scale below the fold**
h1 hits the project's own "~3x body" target. h2 only reaches 1.47x, h3 (used 9 times, on every block title) only 1.16x. The scale is honored once, at the top, then abandoned.
Fix: widen the h2/h3 clamps, or add brown numeral markers ("01 Building," "02 Work") as real section landmarks, already inside brown's licensed "classification" role.
Command: /impeccable typeset

**[P2] Zero imagery on a page meant to persuade in 30 seconds**
No diagrams anywhere, despite three literally-diagrammable systems (approval-queue flow, de-vig pricing waterfall, the H100-to-4 story). This is the most direct, constraint-safe answer to "more complex."
Command: /impeccable delight

**[P2] Brown is licensed but nearly invisible**
Used in exactly two places, both smaller than body text. All three articles currently ship with date: "", so brown's "dating" role never fires on the live site right now.
Fix: give the deck line more size/weight/letter-spacing; once real dates exist, consider a running brown date column in the writing list.
Command: /impeccable colorize

**[P3] Duplicate nav, mismatched labels**
Hero's links and the side rail's labels name the same five anchors two different ways within one scroll of each other.
Command: /impeccable clarify
